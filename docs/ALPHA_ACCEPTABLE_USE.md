# External Alpha Acceptable Use

This document states the operating boundary for invitation access to the
verified OCL runtime alpha. Final commercial terms may replace it before paid
or production use.

## Intended use

Alpha access is for evaluating request-scoped Odoo 19 context in an agent,
assistant, connector, or application. Developers may use returned context in
their authorized evaluation and report integration results or errors.

## Not permitted

- listing, scraping, reconstructing, or redistributing the commercial registry;
- automated attempts to bypass request, module, token, or distinct-entry limits;
- using the service or its outputs to build or train a competing ontology corpus;
- sharing an invitation token with another person or workspace;
- treating alpha access as a production service or SLA;
- claiming that OCL authorizes access to or writes in Odoo;
- sending secrets, credentials, customer records, or unnecessary personal data.

Access can be limited, rotated, suspended, or revoked during the alpha. A
developer should report a suspected token leak promptly and stop using the
affected token.

## Content boundary

The schemas, public examples, and public SDK code remain governed by the public
repository license. Invitation access does not grant the commercial registry,
private verification machinery, raw-corpus redistribution, or embedding rights.

This is an early access policy, not legal advice or a substitute for final
service terms reviewed by counsel.

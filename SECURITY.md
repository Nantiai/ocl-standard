# Security

Do not publish security vulnerabilities, credentials, customer data, or private
registry material in a public issue.

Report sensitive problems to `security@nanti.ai` with:

- affected version and file;
- reproduction steps;
- expected impact;
- whether any private or tenant data was exposed.

This public repository contains formats and example tooling. It does not grant
access to Odoo and does not replace Odoo authentication, ACLs, field access,
record rules, company scope, or workflow methods.

An OCL context pack can describe a security boundary. It cannot authorize a
read or write operation.
